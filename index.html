Taurus UI/UX mockups

Static Tailwind mockups with fake data. Each page maps to an existing Rails view; notes list the main UX problems addressed. Some interactions are wired with a little JS so they can be clicked through.

Cross-cutting changes

  • One header. Nav + project switcher in one dark bar; breadcrumbs show the full path (Project › Event › Lane) instead of only the project.
  • Labeled actions. Icon-only links (road, calendar-check, gear) become labeled buttons or an overflow menu.
  • Consistent status badges. One badge style (dot + label) for event, lane, sync and sale states.
  • Surface problems. Missing floor prices, unsynced lanes and failed selldowns are counted up front and filterable.
  • Safer saves. Sticky save bar with unsaved-change count; warns when saving will sync to the bid engine.
  • Readable dates. Compact absolute dates plus relative time ("starts in 2 days") instead of long strftime strings.
